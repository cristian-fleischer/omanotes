# Escapes and literals

A Windows path: C:\path\to\file and another C:\Users\Example\Notes.

Arithmetic that is not emphasis: 5 \* 3 = 15, and 2 \* 2 \* 2 = 8.

Inline code holding emphasis markers: `a *b* c` and `**not bold**` and `C:\x`.

A wiki link that is not a Markdown link: [[wiki link]] and [[folder/note|alias]].

Backslashes multiply on every save if the file goes through a Markdown writer:
`\\server\share`, `\n`, `\\`, and \_underscored\_.

Autolink: <https://example.com/a_b_c> stays as written.
